# Planner Help

The ULTRASAT Planner includes built-in help resources to assist 
you while working with the application.

## Main Help

You can access the full Planner help at any time by clicking 
the Help button in the main toolbar. This will open the comprehensive online 
help document in your browser, covering all major features and workflows.


## Context-Sensitive Help

Throughout the Planner interface, you will find small help buttons next to 
different sections of the GUI (for example, near plan parameters, target 
lists, and build options). Clicking one of these buttons will open a relevant 
help page for that specific topic — allowing you to get targeted explanations 
and instructions without leaving your current workflow.


## Access Requirements

Help content is hosted online and on the internal SOC server.

Access to internal help pages may require a connection to the WIS VPN.

Make sure you have network access to http://socsrv/ for local HTML help pages.


Use the main Help button to explore the full documentation when learning 
the Planner for the first time. Later, use the section help buttons for 
quick reference while working.
