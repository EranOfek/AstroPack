================================================================================
                    CompositeFun CLASS API REFERENCE
================================================================================
Author: D. Kovaleva (Oct 2025 - Dec 2025)
Description: Composite function framework for transmission calculations with
             parameter mapping, optimization support, and optional position-
             dependent corrections via Tran2D integration.

================================================================================
                    QUICK REFERENCE - ALL METHODS
================================================================================

CONSTRUCTOR:
    CompositeFun()

CORE FUNCTION MANAGEMENT:
    addFun()                        - Add function to composite model
    extractArgFuns()                - Extract parameter info from function handle
    argMapping()                    - Build global parameter index mapping

EVALUATION METHODS:
    preCalc()                       - Pre-calculate fixed-parameter functions
    evaluate()                      - Evaluate with fitted parameters only
    evaluateAllFunParInput()        - Evaluate with all parameters provided
    evaluateWithPosition()          - Evaluate with Tran2D position corrections

TRAN2D POSITION-DEPENDENT METHODS:
    addTran2D()                     - Add Tran2D object for position corrections
    resetTran2DParams()             - Reset Tran2D parameters to initial state
    fitPositionPolynomial()         - Fit position polynomial (linear least squares)
    normalizePositionPolynomial()   - Normalize polynomial at reference position

PARAMETER GETTERS:
    numAllFunPar()                  - Count all function parameters
    namesAllFunPar()                - Names of all function parameters
    valuesAllFunPar()               - Values of all function parameters
    getAllFunPar()                  - All function parameters as structure
    numFittedPar()                  - Count fitted parameters
    namesFittedPar()                - Names of fitted parameters
    getFittedPar()                  - Detailed fitted parameter info
    getTran2DPar()                  - Get Tran2D parameters as structure
    getAllFunParWithTran2D()        - Get combined function+position parameters
    namesFuns()                     - Function names and descriptions
    allFunsStruct()                 - Complete Funs structure

PARAMETER SETTERS:
    setAllFunPar()                  - Update function parameters and fit flags
    setTran2DParams()               - Update Tran2D parameters from vector

VALIDATION:
    checkOverlappingParamConsistency() - Validate overlapping parameters

HIGH-LEVEL METHODS:
    modelCompositeFun() [STATIC]    - Build model from specification list
    costFun()                       - Calculate cost for optimization
    fitParCompositeFun()            - Fit parameters with sigma clipping
                                      Supports single-stage or multi-stage optimization

================================================================================
                    CORE FUNCTION MANAGEMENT
================================================================================

addFun(Obj, Desc, Handle, ArgNames, varargin)
    Add function to composite model

    Input:
        Desc      - Function description (string)
        Handle    - Function handle: Y = F(X, Par, OptionalArgs{:})
        ArgNames  - Parameter info struct ([] for auto-extraction)
        varargin  - 'Par', values, 'FitPar', flags, 'OptionalArgs', {...}

    Updates: Obj.Funs
    Calls:   argMapping() to update global parameter mapping

    Example:
        Model.addFun('Ozone', @astro.transmission.ozoneTransmission, [], ...
            'Par', [30, 300], 'FitPar', [false, true]);

extractArgFuns(~, FunctionHandle) [STATIC]
    Extract parameter information from function handle

    Input:  FunctionHandle
    Output: ArgNames structure (.Name, .Description, .Min, .Max)
    Method: Calls FunctionHandle('GetArgNames', true)

argMapping(Obj)
    Build global parameter index mapping

    Updates: Obj.Funs.ArgMapping
    Called:  Automatically by addFun()


================================================================================
                        EVALUATION METHODS
================================================================================

preCalc(Obj, X)
    Pre-calculate functions with all fixed parameters

    Input:  X - Evaluation points
    Stores: Results in Obj.Funs.PreCalc
    Use:    Optimization for functions with all(FitPar==false)

evaluate(Obj, X, FittedPars)
    Evaluate with fitted parameters only

    Input:
        X          - Evaluation points
        FittedPars - Values for parameters with FitPar==true
    Output: Y - Combined function result

    Requires: Call preCalc(X) first if any functions have all-fixed parameters
    Combines: Functions using FunOperator (default '*')

evaluateAllFunParInput(Obj, X, AllFunPar)
    Evaluate with all function parameters provided explicitly

    Input:
        X         - Evaluation points
        AllFunPar - Full function parameter vector [N_params x 1]
    Output: Y - Combined function result

    Example:
        Y = Model.evaluateAllFunParInput(Lambda, [30, 300, 0.05, 1.2]);

evaluateWithPosition(Obj, Lambda, X, Y, Args)
    Evaluate transmission with Tran2D position corrections

    Input:
        Lambda - Wavelength grid [N_lambda x 1]
        X      - Source X coordinates [N_sources x 1]
        Y      - Source Y coordinates [N_sources x 1]
        Args   - 'TransParams' (optional parameter override)

    Output: Transmission matrix [N_sources x N_lambda]

    Requires: UseTran2D=true, Tran2DObj exists
    Formula:  Trans(i,j) = BaseTrans(j) × 10^(+0.4 × FieldCorrectionMag(i))

    Note: Uses +0.4 factor (not -0.4) due to sign convention in fitPositionPolynomial


================================================================================
                    TRAN2D POSITION-DEPENDENT METHODS
================================================================================

addTran2D(Obj, Tran2DObj, Args)
    Add Tran2D object for position-dependent corrections

    Input:
        Tran2DObj - Tran2D object with ParNX, ParNY configured
        Args      - 'X_ref', 'Y_ref' (reference position)
                    'Verbose' (logical)

    Sets: Obj.Tran2DObj, Obj.UseTran2D = true
    May call: normalizePositionPolynomial() if X_ref, Y_ref provided

    Example:
        T2D = Tran2D('cheby1_4_xt');
        T2D.ParNX = [863, 863]; T2D.ParNY = [863, 863];
        T2D.ParX = zeros(1, 10);
        Model.addTran2D(T2D, 'X_ref', 863, 'Y_ref', 863);

fitPositionPolynomial(Obj, X, Y, MagResid, Args)
    Fit position polynomial using linear least squares

    Input:
        X, Y     - Source coordinates [N_sources x 1]
        MagResid - Magnitude residuals [N_sources x 1]
                   Convention: Observed - Predicted
        Args     - 'Method' ('\' | 'lscov', default '\')
                   'ErrMag' (errors for lscov method)
                   'Verbose' (logical)

    Output:
        FitPosResult - Fitting results (.ParX, .RmsX)
        Obj          - Updated object with fitted Tran2DObj.ParX

    Note: Negates MagResid (-MagResid) to match legacy transmissionFit convention
          Combined with +0.4 evaluation factor, ensures transmission ≤ 1.0

    Calls: Tran2DObj.fitDesignMatrix()

normalizePositionPolynomial(Obj, X_ref, Y_ref, Args)
    Normalize position polynomial at reference position

    Input:  X_ref, Y_ref - Reference coordinates
            Args - 'Verbose' (logical)

    Effect: Sets correction = 0 at reference position
    Method: ParX(1) ← ParX(1) - correction_at_reference

getTran2DPar(Obj)
    Get Tran2D parameters as parameter structure

    Output: ParStruct (.Name, .Val, .FitPar)
            Returns empty structure if UseTran2D is false
    Use:    For combining with wavelength parameters

setTran2DParams(Obj, ParValues, Args)
    Update Tran2D parameters from vector

    Input:  ParValues - New parameter values [1 x N_params]
            Args - 'Verbose' (logical)

    Updates: Obj.Tran2DObj.ParX

getAllFunParWithTran2D(Obj)
    Get combined function + position parameters

    Output: AllFunParStruct with all parameters
            (.Name, .Val, .FitPar)

    Calls: getAllFunPar(), getTran2DPar()
    Use:   Unified parameter management

                    HIGH-LEVEL METHODS

modelCompositeFun(FunList, Args) [STATIC]
    Build CompositeFun model from specification list

    Input:
        FunList - Struct array with fields:
                  .name, .handle, .handletype, .params, .paraminfo
        Args    - 'MetadataValues' (struct for parameter injection)
                  'UseTran2D' (logical, default false)
                  'Tran2DType' (string, default 'cheby1_4_xt')
                  'XPixel', 'YPixel' (detector dimensions)
                  'Verbose' (logical)

    Output: CompositeFun object

    Example:
        Model = tools.math.fun.CompositeFun.modelCompositeFun(TransFunList, ...
            'MetadataValues', struct('ZenithAngle_deg', 45), ...
            'UseTran2D', true, 'Tran2DType', 'cheby1_4_xt');

costFun(Obj, InputValues, ObservedValues, Args)
    Calculate residuals, cost, and predictions for optimization

    Input:
        InputValues     - Input grid [N_input x 1] (e.g., wavelength)
        ObservedValues  - Observations [N_obs x 1]
        Args:
            'TransParams'        - Parameter override vector
            'X', 'Y'             - Source coordinates for Tran2D
            'WeightMatrix'       - For weighted integration [N_obs x N_input]
                                   For TransmissionMode: [N_SpecWvl x N_obs] calibrator spectra
            'IntegrationDim'     - Integration dimension (1 or 2)
            'TransmissionMode'   - Enable transmission-specific mode (logical)
            'GaiaWavelength'     - Spectral wavelength grid [nm]
            'ExpTime'            - Exposure time [s] (default 20)
            'Aperture_area_m2'   - Aperture area [m²] (default pi*0.1397²)
            'CostType'           - 'sse' | 'mae' | 'rmse' (default 'sse')
            'ValInp', 'Verbose'

    Output:
        Residuals       - [N_obs x 1]
        Cost            - Scalar
        PredictedValues - [N_obs x 1]

    Modes:
        TransmissionMode - Integrates Gaia spectra × transmission,
                           converts to photons, returns magnitude residuals
        WeightMatrix     - Weighted integration (general)
        Direct           - Direct comparison (NumInput == NumObs)

    Example:
        [ResMag, Cost, PredFlux] = Model.costFun(Lambda, ObsFlux, ...
            'WeightMatrix', GaiaSpec, 'TransmissionMode', true, ...
            'X', X, 'Y', Y, 'ExpTime', 20);

fitParCompositeFun(Obj, InputValues, ObservedValues, Args)
    Fit parameters with sigma clipping and optional multi-stage optimization

    Input:
        InputValues     - Input grid [N_input x 1]
        ObservedValues  - Observations [N_obs x 1]
        Args:
            'CostArgs'             - Struct for costFun arguments
            'X', 'Y'               - Source coordinates
            'FitTransmission'      - Fit base function parameters (logical)
            'FitPosition'          - Fit Tran2D parameters (logical)
            'FreeParamIndices'     - Specific parameters to fit
            'SigmaClip'            - Enable sigma clipping (logical)
            'SigmaThresh'          - Threshold [sigma] (default 3.0)
            'SigmaIter'            - Max iterations (default 5)
            'OptimOptions'         - Options for lsqnonlin
            'OptimizationSequence' - Multi-stage sequence (struct array)
            'Verbose'

    Output:
        Obj        - Updated object with fitted parameters
        FitResult  - Single-stage: Struct (.Cost, .RMS, .Residuals, .NumObs)
                     Multi-stage: Results array for each stage

    OptimizationSequence format:
        OptSeq(i).stagename    - Stage name
        OptSeq(i).freeparams   - [] for field correction, or struct array:
                                 .function, .parameter
        OptSeq(i).sigmaclip    - Enable sigma clipping (logical)
        OptSeq(i).sigmathresh  - Threshold [sigma]
        OptSeq(i).sigmaiter    - Max iterations
        OptSeq(i).description  - Stage description

    Strategy:
        - Nonlinear (transmission): tools.math.fit.lsqNonLinWithFixed
        - Linear (position):        fitPositionPolynomial()
        - Sigma clipping:           MAD-based outlier detection, propagates between stages

    Example (single-stage):
        [Model, FitResult] = Model.fitParCompositeFun(Lambda, ObsFlux, ...
            'X', X, 'Y', Y, 'SigmaClip', true);

    Example (multi-stage):
        OptSeq(1).stagename = 'AerosolOpt';
        OptSeq(1).freeparams(1).function = 'Aerosol';
        OptSeq(1).freeparams(1).parameter = 'TauAod500';
        OptSeq(1).sigmaclip = true;
        OptSeq(1).sigmathresh = 3.0;
        OptSeq(1).sigmaiter = 3;
        OptSeq(1).description = 'Fit aerosol optical depth';

        OptSeq(2).stagename = 'FieldCorr';
        OptSeq(2).freeparams = [];  % Empty for field correction
        OptSeq(2).sigmaclip = true;
        OptSeq(2).sigmathresh = 2.0;
        OptSeq(2).sigmaiter = 2;
        OptSeq(2).description = 'Position-dependent correction';

        [Model, FitResult] = Model.fitParCompositeFun(Lambda, ObsFlux, ...
            'CostArgs', CostArgs, 'X', X, 'Y', Y, ...
            'OptimizationSequence', OptSeq, 'Verbose', true);


================================================================================
                    METHOD INTERACTION MAP
================================================================================

Construction:
    CompositeFun() → addFun() → [extractArgFuns()] → argMapping()

Static Builder:
    modelCompositeFun() → CompositeFun() → addFun() (×N)
                       → setAllFunPar() → [addTran2D()]

Evaluation (no Tran2D):
    preCalc() → evaluate()  OR  evaluateAllFunParInput()

Evaluation (with Tran2D):
    evaluateWithPosition() → evaluateAllFunParInput()
                          → Tran2DObj.forward()

Position Fitting:
    fitPositionPolynomial() → Tran2DObj.design_matrix()
                           → Tran2DObj.fitDesignMatrix()

Full Optimization (single-stage):
    fitParCompositeFun() → [Transmission: lsqNonLinWithFixed → costFun()]
                        → [Position: fitPositionPolynomial()]
                        → [Sigma clipping iteration]

Full Optimization (multi-stage):
    fitParCompositeFun() → fitMultiStage()
        → For each stage: fitParCompositeFun() (recursive, single-stage)
        → Propagate sigma clipping between stages

Parameter Management:
    getAllFunPar() → modify → setAllFunPar()
    getAllFunParWithTran2D() (includes Tran2D + function params)

================================================================================
                        TYPICAL USAGE PATTERNS
================================================================================

Pattern 1: Manual Construction
    Model = tools.math.fun.CompositeFun();
    Model.addFun('Ozone', @astro.transmission.ozoneTransmission, [], ...
        'Par', [30, 300], 'FitPar', [false, true]);
    Model.addFun('Aerosol', @astro.transmission.aerosolTransmission, [], ...
        'Par', [30, 0.05, 1.2], 'FitPar', [false, true, false]);
    Y = Model.evaluateAllFunParInput(Lambda, [30, 300, 30, 0.05, 1.2]);

Pattern 2: Static Builder with Tran2D
    Model = tools.math.fun.CompositeFun.modelCompositeFun(TransFunList, ...
        'MetadataValues', struct('ZenithAngle_deg', 45), ...
        'UseTran2D', true, 'Tran2DType', 'cheby1_4_xt', ...
        'XPixel', 1727, 'YPixel', 1727);
    Trans = Model.evaluateWithPosition(Lambda, X, Y);

Pattern 3: Single-Stage Optimization
    Model = tools.math.fun.CompositeFun.modelCompositeFun(TransFunList, ...
        'UseTran2D', true);
    AllPar = Model.getAllFunPar();
    AllPar.FitPar([2,4]) = true;
    Model.setAllFunPar(AllPar);

    CostArgs = struct('WeightMatrix', GaiaSpec, 'TransmissionMode', true, ...
                      'ExpTime', 20, 'Aperture_area_m2', pi*0.1397^2);
    [Model, Result] = Model.fitParCompositeFun(Lambda, ObsFlux, ...
        'CostArgs', CostArgs, 'X', X, 'Y', Y, ...
        'FitTransmission', true, 'FitPosition', true, ...
        'SigmaClip', true, 'Verbose', true);

Pattern 4: Multi-Stage Optimization
    OptSeq(1).stagename = 'AerosolOpt';
    OptSeq(1).freeparams(1).function = 'Aerosol';
    OptSeq(1).freeparams(1).parameter = 'TauAod500';
    OptSeq(1).sigmaclip = true;
    OptSeq(1).sigmathresh = 3.0;
    OptSeq(1).sigmaiter = 3;
    OptSeq(1).description = 'Optimize aerosol optical depth';

    OptSeq(2).stagename = 'FieldCorr';
    OptSeq(2).freeparams = [];
    OptSeq(2).sigmaclip = true;
    OptSeq(2).sigmathresh = 2.0;
    OptSeq(2).sigmaiter = 2;
    OptSeq(2).description = 'Position-dependent field correction';

    Model = tools.math.fun.CompositeFun.modelCompositeFun(FunList, ...
        'UseTran2D', true);
    CostArgs = struct('WeightMatrix', GaiaSpec, 'TransmissionMode', true, ...
                      'ExpTime', 20, 'Aperture_area_m2', pi*0.1397^2);
    [Model, FitResult] = Model.fitParCompositeFun(Lambda, ObsFlux, ...
        'CostArgs', CostArgs, 'X', X, 'Y', Y, ...
        'OptimizationSequence', OptSeq, 'Verbose', true);

    fprintf('Stage 1 RMS: %.4f mag\n', FitResult(1).RMS);
    fprintf('Stage 2 RMS: %.4f mag\n', FitResult(2).RMS);


================================================================================
                        IMPORTANT NOTES
================================================================================

Sign Convention (Tran2D Integration):
    - fitPositionPolynomial() negates MagResid: ParX = Hx \ (-MagResid)
    - evaluateWithPosition() uses +0.4 factor (not -0.4)
    - Combined effect matches legacy transmissionFit behavior
    - Ensures transmission ≤ 1.0 for positive residuals

Transmission Mode:
    - Automatically integrates Gaia spectra × transmission
    - Converts to photon flux using exposure time and aperture area
    - Returns magnitude residuals: DeltaMag = 2.5*log10(Predicted/Observed)
    - Convention: Residual = Observed - Predicted (magnitude space)

Multi-Stage Optimization:
    - Sigma clipping propagates between stages (outliers removed permanently)
    - Each stage can have different sigma clipping thresholds
    - Empty freeparams → field correction stage (linear fit)
    - Non-empty freeparams → transmission parameter stage (nonlinear fit)

Parameter Management:
    - Global parameter indexing via ArgMapping
    - Metadata injection by parameter name (case-sensitive)
    - Overlapping parameters (same name) automatically shared across functions
