# 09 — Glossary

| Term | Meaning |
|------|---------|
| AstroPack | This repository; also known as MAATv2 |
| MAATv2 | MATLAB Astronomy & Astrophysics Toolbox, version 2 |
| ULTRASAT | Ultraviolet Transient Astronomy Satellite — UV space telescope mission |
| LAST | Large-array Survey Telescope — ground-based survey telescope |
| catsHTM | Catalog access system using HDF5/HTM (Hierarchical Triangular Mesh) for fast cone searches on large catalogs |
| WCS | World Coordinate System — mapping between pixel coordinates and sky coordinates |
| PSF | Point Spread Function — model of how a point source appears in an image |
| MEX | MATLAB Executable — compiled C/C++ functions callable from MATLAB |
| DataModule | State mediator class in the planner subsystem; bridges GUI, core logic, and API |
| uplanner | Core ULTRASAT planner logic class (deterministic, no UI) |
| IPC | Inter-Process Communication — here, file-based exchange between MATLAB and Python |
| TOO | Target of Opportunity — time-critical observation triggered by external alerts |
| SNR | Signal-to-Noise Ratio |
| BitMask | Pixel-level quality flags stored as bitmask images; configured via `BitMask.*.yml` |
| imProc | Image processing algorithm package (`+imProc`) |
| App Designer | MATLAB GUI framework used for all graphical interfaces in this project |
